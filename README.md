# 打磨录入工具

基于 Python + PySide6 + pywin32 的 WPS 表格录入工具，用于半自动录入车间生产数据。

## 背景

车间产量记录以纸质形式保存，录入 Excel 时需人工逐条对照型号、日期，手动找到对应单元格。
型号多达几十种，日期 1~31 行，人工定位极易填错行、填错列，每月重复此流程，耗时且枯燥。

本工具将"手动找位置填表"变成"输入型号数量自动定位写入"，降低出错率，提高效率。

## 功能

- **录入**：输入日期、型号、数量，回车即写入 WPS 当前活动单元格
- **数量表达式**：支持 `600/2` 这种简单运算
- **动态插入列**：新号按规则排序自动插入到正确位置
- **型号排序**：支持纯数字、字母数字混合、中文后缀（帽檐/下巴/尾翼/顶盖）
- **拼音缩写匹配**：输入 `X65MY` 可匹配到 `X65帽檐`
- **撤回**：撤销上一次录入
- **多人合作**：输入总数，自动平分到选中的多个 sheet
- **批量录入**：固定型号，依次录入多个人员的数量；录入后可在当前 sheet 停留一段时间供核对，再自动跳转下一位（延迟时间可调，默认 0.5 秒）
- **查询某天记录**：查询任意已打开工作簿中，某一天（几号）各人员做了哪些型号、分别是多少个；支持勾选 sheet 或直接输入人员名单
- **单价自动填充**：干磨表从独立单价表读取，写入 35 行
- **公式维护**：自动写入求和、乘法、总计公式
- **清理空列**：一键删除 34 行为 0 的型号列
- **修帽子合计统计**：按分页规则生成每个人的型号汇总
- **界面**：窗口置顶、透明度可调、方向键导航

## 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows |
| WPS | 必须安装 WPS Office（32 位或 64 位均可） |
| Python | 3.10+（源码运行） |
| 依赖库 | pywin32, PySide6, openpyxl |
