# 打磨录入工具 (damo_tool)

基于 Python + PySide6 + pywin32 的 WPS 表格极速录入工具，用于半自动录入车间生产数据。

## 背景

车间产量记录以纸质形式保存，录入 Excel 时需人工逐条对照型号、日期，手动找到对应单元格。
型号多达几十种，日期 1~31 行，人工定位极易填错行、填错列，每月重复此流程，耗时且枯燥。

本工具将"手动找位置填表"变成"输入型号数量自动定位写入"，降低出错率，提高效率。

## 核心功能（完全对应主界面）

- **极速录入**：输入人员、日期、型号及数量表达式（支持 `600/2` 等算式），回车即自动写入。
- **撤回**：一键撤销上一次操作。
- **多人合作**：输入总数，自动平分给多个选中的人员。
- **批量录入**：固定型号，依次快速录入多名人员。支持自定义延迟跳转（如 500 毫秒），录入完停留供核对后自动切到下一个人。
- **单价与公式维护**：
  - 支持加载、重载独立单价表。
  - 自动检查并补全缺失单价。
  - 检查修正公式：一键全表校验并修正求和、乘法等公式。
- **数据清理**：
  - 清理空列：自动删除总计为 0 的无效型号列。
  - 清理离职表：自动删除完全没有数据的人员 sheet。
  - 新增人员：一键生成带有标准格式的新 sheet。
- **统计与查询**：
  - 修帽子合计统计：自动生成全员工序的汇总对比表。
  - 查询某天记录：查询特定人员在某一天的录入详情。
  - **跨表综合查询**：一键查询某个员工在多个工作簿中的产量，支持自动提取所有表名及人员，极速汇总。
- **UI 体验**：自适应流式布局（窗口缩小不挤压）、窗口置顶、透明度调节、批量跳转延迟可调。

## 安装

```bash
pip install pywin32 PySide6 openpyxl

使用
打开 WPS，打开目标排单 Excel 文件；

运行 python main.py；

程序会自动识别当前活动的 WPS 工作簿和人员 sheet。

基础录入
确认当前人员，输入「日期（几号）」、「型号」、「数量表达式」，按回车即可快速写入。

如果录错了，可按 Ctrl+Z 或点击「撤回」按钮。

批量录入
点击「批量录入」按钮，在弹窗中勾选多个人员并确认。

输入型号，随后依次输入每个人的数量并回车，界面会自动延迟跳转（延迟可在主界面下方调节）。

单价与公式维护
首次使用点击「单价表」选择文件，程序会自动加载。

点击「检查缺失单价」可以查看哪些型号没有配置价格。

点击「检查修正公式」可修复因为各种原因损坏的表格公式。

跨表综合查询
点击「🔍 跨表综合查询」按钮。

下拉框会自动拉取当前打开的所有工作簿及人名（去重并标注来源）。

可选填日期，留空则查询该员工所有日期的总计。

勾选工作簿后点击「开始查询」即可极速汇总。
