# 打磨录入工具 (damo_tool)

基于 Python + PySide6 + pywin32 的 WPS 表格极速录入工具，用于半自动录入车间生产数据。

## 背景

车间产量记录以纸质形式保存，录入 Excel 时需人工逐条对照型号、日期，手动找到对应单元格。
型号多达几十种，日期 1~31 行，人工定位极易填错行、填错列，每月重复此流程，耗时且枯燥。

本工具将"手动找位置填表"变成"输入型号数量自动定位写入"，降低出错率，提高效率。

## 核心功能（完全对应主界面）

- **极速录入**：输入人员、日期、型号及数量表达式（支持 `600/2` 等算式），回车即自动写入。内置防抖机制，输入框自动锁定，防止高频输入导致数据串行。
- **撤回与回退**：
  - 支持一键撤销上一步操作，且操作栈无限制，可一步一步撤回多次录入。
  - 支持“回退”（即恢复刚才撤回的操作）。
  - **操作预览**：在点击撤回或回退时，会弹窗精准提示具体变动（例如：“将张三表 B5 单元格的 150 恢复为 100”），彻底告别盲盒操作。
- **多人合作**：输入总数，自动平分给多个选中的人员。处理时附带实时进度提示，并优化了底层写入速度。
- **批量录入**：固定型号，依次快速录入多名人员。支持自定义延迟跳转（如 500 毫秒），录入完停留供核对后自动切到下一个人。
- **数据维护工具**：
  - **清空某日数据**：支持按日期（如 27 号）一键清空指定人员（支持多选）在该日的所有工序数据。
  - **修改表头型号**：支持批量替换表格中写错的型号（如将 22.5 替换为 225），并强制转为大写。
- **单价与公式维护**：
  - 支持加载、重载独立单价表。
  - **智能缺失溯源**：自动检查缺失单价，不仅列出型号，还会精准显示是**哪位员工**在**哪几天（几号）**填过该型号，方便直接翻阅纸质工单核对。
  - 检查修正公式：一键全表校验并修正求和、乘法等公式，**操作完毕后会强制兜底保存**。
- **排版检查**：一键检查并修正全工作簿的打印排版（统一边距：左边距 2cm、右/上/下边距 1cm；强制设为**横向打印**）。
- **数据清理**：
  - 清理空列：自动删除总计为 0 的无效型号列（带强制保存）。
  - 清理离职表：自动删除完全没有数据的人员 sheet（带强制保存）。
  - 新增人员：一键生成带有标准格式的新 sheet。
- **统计与查询**：
  - 修帽子合计统计：自动生成全员工序的汇总对比表。
  - 查询某天记录：查询特定人员在某一天的录入详情。
  - **跨表综合查询**：
    - 支持**模糊搜索**人员姓名（如输入“李金”自动提示“李金锋”）。
    - **智能联动过滤**：选中人员后，下方工作簿列表自动只保留该员工干过活的表格。
    - **极速批量读取**：底层弃用逐格读取，改用 Range 区域批量读取，极大提升多表综合查询速度。
- **UI 体验**：自适应流式布局（窗口缩小不挤压）、窗口置顶、透明度调节、批量跳转延迟可调、静默无黑窗启动。

## 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows |
| WPS | 必须安装 WPS Office（32 位或 64 位均可） |
| Python | 3.10+（源码运行） |
| 依赖库 | pywin32, PySide6, openpyxl |

## 安装与打包

```bash
# 安装依赖
pip install pywin32 PySide6 openpyxl

# 打包成独立 exe（可选）
pyinstaller -F -w main.py

使用说明
打开 WPS，打开目标排单 Excel 文件；
运行 python main.py 或双击打包好的 .exe（或使用项目自带的 run.bat 静默启动）；
程序会自动识别当前活动的 WPS 工作簿和人员 sheet。

基础录入与撤销
确认当前人员，输入「日期（几号）」、「型号」、「数量表达式」，按回车即可快速写入。

如果录错了，可点击「撤回」按钮，点击「回退」可恢复刚才撤回的内容。操作前均会有弹窗提示。

数据维护
点击「清空某日数据」：输入日期并勾选人员，一键清除当日数据。

点击「修改表头型号」：输入旧型号与新型号，全表一键替换并转大写。

跨表综合查询
点击「🔍 跨表综合查询」按钮，在人员下拉框中输入名字模糊搜索，勾选工作簿即可一键极速汇总。

文件说明
文件	用途
main.py	入口文件
ui_main.py	主界面 + 交互逻辑
wps_connector.py	WPS COM 接口封装
entry_logic.py	录入、撤回、批量、汇总核心逻辑
model_sort.py	型号排序及拼音匹配规则
price_loader.py	单价表读取
run.bat	无黑窗静默启动脚本
已知限制
仅支持 Windows + WPS，不支持 Microsoft Excel。

依赖已打开的 WPS 实例，不支持后台静默处理。

单价表固定读取 Sheet1 的前三列（型号、基础价、后缀价）。
